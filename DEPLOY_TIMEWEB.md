# Публикация сайта «У Михалыча» на Timeweb

Сайт статический. Это набор готовых файлов: HTML, CSS, JavaScript, шрифты,
картинки и видео. **Node.js, npm и какие-либо процессы на сервере не нужны** —
подойдёт обычный виртуальный хостинг.

Анимации, плавная прокрутка, пар на canvas, видео первого экрана и живой
статус расписания работают в браузере посетителя, поэтому серверная часть
не требуется.

---

## Быстрый путь: загрузить готовый сайт

Собирать проект не нужно — архив уже собран автоматически.

1. Открыть **[Releases](../../releases)** репозитория.
2. Выбрать релиз **`timeweb-latest`** (заголовок «Timeweb Production»).
3. Скачать единственный файл **`banya-timeweb-production.zip`**.
4. Распаковать архив и загрузить **его содержимое** в `public_html`.

Прямая ссылка, которая всегда ведёт на свежую сборку:

```
https://github.com/newgrubby/banyamihalich/releases/download/timeweb-latest/banya-timeweb-production.zip
```

### Как именно раскладывать файлы

Внутри архива файлы лежат **без обёртки**: никакой вложенной папки `out/`
или `banya-timeweb-production/` там нет. Раскладывать нужно так, чтобы
`index.html` оказался непосредственно в `public_html`:

```
public_html/
├── .htaccess          ← скрытый файл, загрузить обязательно
├── index.html         ← должен лежать прямо здесь
├── 404.html
├── robots.txt
├── sitemap.xml
├── _next/             ← JavaScript, CSS и шрифты
├── art/               ← векторная графика
├── photos/            ← фотографии бани
├── hero-loop.mp4      ← видео первого экрана
├── hero-poster.avif / .webp / .png
├── og.jpg             ← картинка для соцсетей
├── apple-icon.png
└── icon.svg
```

**Неправильно** — сайт не откроется:

```
public_html/
└── banya-timeweb-production/
    └── index.html      ← вложенная папка, так нельзя
```

> **Про `.htaccess`.** Файл начинается с точки, и файловые менеджеры часто
> прячут такие файлы. В файловом менеджере Timeweb нужно включить показ
> скрытых файлов, в FileZilla — «Сервер → Принудительно отображать скрытые
> файлы». Без `.htaccess` сайт откроется, но не будет редиректа на HTTPS,
> сжатия и кеширования.

Больше ничего делать не нужно: ни установки зависимостей, ни сборки,
ни запуска приложения.

## Домен

Сборка выполнена под адрес **`https://баниумихалыча.рф`**.

В служебных файлах домен записан в стандартной ASCII-форме
`https://xn--80aaab0bawfh5dya0a5c.xn--p1ai` — это тот же самый адрес.
Так требует спецификация: поисковики и валидаторы понимают именно её,
а в браузере адрес по-прежнему отображается кириллицей.

Домен подставляется на этапе сборки в `canonical`, Open Graph, JSON-LD,
`sitemap.xml` и `robots.txt`. **При смене домена сайт нужно пересобрать** —
поменять значение `NEXT_PUBLIC_SITE_URL` в
[`.github/workflows/build-timeweb.yml`](.github/workflows/build-timeweb.yml)
и запушить изменение. Новый архив соберётся сам.

## Настройки после загрузки

### HTTPS

В `.htaccess` включено принудительное перенаправление на HTTPS.
**Включать сайт следует после выпуска SSL-сертификата** — иначе
браузер уйдёт в бесконечный редирект. Если сертификата пока нет,
закомментируйте (поставьте `#` в начале строк) блок «1. Принудительный HTTPS».

### www или без www

Перенаправление между `сайт.рф` и `www.сайт.рф` **по умолчанию выключено**.
Включать его нужно, когда оба адреса привязаны к хостингу: в `.htaccess`
в блоке «2. Канонический адрес» снять `#` с нужной пары строк —
там заготовлены оба варианта.

## Обновление сайта

Правки вносятся в репозиторий, архив пересобирается автоматически.

1. Изменить нужное:
   * тексты, цены, расписание, контакты → [`lib/content.ts`](lib/content.ts);
   * фотографии → [`public/photos/`](public/photos);
   * вёрстка и стили → [`components/`](components).
2. Закоммитить и запушить в ветку `main`.
3. GitHub Actions соберёт проект и обновит релиз `timeweb-latest`
   (около полутора минут). Ход сборки виден на вкладке **Actions**.
4. Скачать новый `banya-timeweb-production.zip` из релиза.
5. Загрузить содержимое в `public_html` с заменой файлов.

> При обновлении старый каталог `_next/` можно удалить перед загрузкой:
> имена файлов в нём содержат хеш содержимого, поэтому от прошлых сборок
> остаётся мусор. Это не обязательно, но экономит место.

Ссылка на скачивание не меняется от сборки к сборке — она всегда ведёт
на последнюю версию.

## Сборка вручную (если нужна)

Обычно не требуется: этим занимается GitHub Actions. Но собрать можно и локально.

Нужен **Node.js 22** (минимум 20.9, зафиксировано в `package.json` → `engines`).

```bash
npm ci
NEXT_PUBLIC_SITE_URL=https://баниумихалыча.рф npm run build
```

Готовый сайт появится в каталоге `out/`. Перед упаковкой из него удаляются
`hero.mp4` и `hero.png` — это исходники для `npm run media`, сам сайт
на них не ссылается.

Сборка не обращается в интернет: шрифты лежат в репозитории
([`app/fonts/`](app/fonts)), внешних CDN нет. Доступ нужен только к
реестру npm на шаге `npm ci`.

## Что проверить после публикации

1. **Главная открывается** по адресу домена, заголовок
   «От души. С веничком. По-русски.» на месте.
2. **Видео первого экрана** проигрывается и зацикливается; до его загрузки
   виден постер.
3. **Шрифты**: заголовки — Playfair Display, текст — Inter. В DevTools →
   Network ровно три файла `.woff2` из `/_next/static/media/` и **ни одного**
   запроса к `fonts.googleapis.com` или `fonts.gstatic.com`.
4. **Анимации**: плавная прокрутка, появление блоков при скролле, пар,
   кастомный курсор на десктопе.
5. **Статус расписания** в шапке показывает актуальное «Открыто до 23:00» /
   «Откроется в 11:00» / «Сегодня закрыто». Считается по московскому времени
   в браузере, от настроек сервера не зависит.
6. **Телефон**: ссылки `tel:+79671304027`, на мобильном открывается набор.
7. **VK**: ведёт на `https://vk.ru/baniapposad`.
8. **Карта**: кнопка загружает виджет Яндекс.Карт, «Построить маршрут»
   открывает маршрут до Корнево-Юдинского переулка, 10.
9. **SEO**: `/robots.txt` и `/sitemap.xml` открываются и содержат боевой домен;
   в исходном коде страницы есть `canonical`, `og:image` и разметка
   организации JSON-LD.
10. **Мобильная версия**: нижняя панель «Позвонить / Маршрут» зафиксирована,
    горизонтальной прокрутки нет.
11. **Консоль браузера** без ошибок.

## Устройство репозитория

| Что | Где |
|---|---|
| Тексты, цены, расписание, контакты | [`lib/content.ts`](lib/content.ts) |
| Компоненты и стили | [`components/`](components) |
| Шрифты (локальные, OFL 1.1) | [`app/fonts/`](app/fonts) |
| Медиа и статика | [`public/`](public) |
| Настройки Apache | [`public/.htaccess`](public/.htaccess) |
| Сборка пакета | [`.github/workflows/build-timeweb.yml`](.github/workflows/build-timeweb.yml) |

Каталог `out/` и сам архив в репозитории не хранятся: они полностью
воспроизводятся сборкой, поэтому держать их в истории незачем.
