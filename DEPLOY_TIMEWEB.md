# Деплой сайта «У Михалыча» на Timeweb Cloud

Проект — Next.js 15 (App Router) в режиме SSR/SSG на Node.js. Внешних сервисов,
баз данных и секретов нет: весь контент лежит в `lib/content.ts`, все медиа — в `public/`.

---

## 1. Требуемая версия Node.js

| | |
|---|---|
| **Рекомендуется** | **Node.js 22 LTS** (проверено также на 20 LTS и 24) |
| Минимум | 20.9.0 |
| npm | 10 или новее |

Ограничение зафиксировано в `package.json` → `engines`: `>=20.9.0 <25`.
В панели Timeweb выбирайте тип приложения **Next.js** или **Node.js**, версия 22.

---

## 2. Команда установки

```bash
npm ci
```

> `npm ci` ставит зависимости строго по `package-lock.json`.
> **Не добавляйте `--omit=dev`**: `typescript` и `@types/*` нужны на этапе сборки.
> Отсекать dev-зависимости можно только после `npm run build` (`npm prune --omit=dev`).

---

## 3. Команда сборки

```bash
npm run build
```

Сборка занимает ~1 минуту и создаёт каталог `.next/`.

**Внешних обращений во время сборки нет.** Шрифты Playfair Display и Inter
лежат в репозитории (`app/fonts/*.woff2`) и подключаются через `next/font/local`,
поэтому сборка не ходит в `fonts.googleapis.com` / `fonts.gstatic.com`
и проходит без доступа в интернет (нужен только доступ к npm-реестру для `npm ci`).
В рантайме шрифты раздаются с вашего домена из `/_next/static/media/`.

---

## 4. Команда запуска (production)

```bash
npm run start
```

Это `next start`. Он слушает `0.0.0.0` и порт из переменной окружения `PORT`
(по умолчанию 3000). Отдельный сервер писать не нужно.

Если панель требует явную команду одной строкой:

```bash
npm ci && npm run build && npm run start
```

---

## 5. Переменные окружения

Секретов нет. Все переменные необязательные — шаблон лежит в `.env.example`.

| Переменная | Обязательна | Значение по умолчанию | Зачем |
|---|---|---|---|
| `PORT` | нет | `3000` | Порт HTTP-сервера. Timeweb обычно подставляет сам. |
| `NODE_ENV` | нет | `production` | Выставляется хостингом автоматически. |
| `NEXT_PUBLIC_SITE_URL` | нет | `https://banya-mihalycha.ru` | Канонический домен: `canonical`, Open Graph, JSON-LD, `robots.txt`, `sitemap.xml`. |

`NEXT_PUBLIC_SITE_URL` задавайте **только** если сайт открывается не на рабочем домене
(тестовый стенд `*.twc1.net` и т. п.). Формат: с протоколом, без слэша в конце.
Переменная читается на этапе сборки — после её изменения нужен повторный `npm run build`.

---

## 6. Порт

- Приложение слушает `process.env.PORT`; если переменная не задана — `3000`.
- Хост: `0.0.0.0` (доступен из-под прокси Timeweb).
- HTTPS и проксирование настраиваются на стороне Timeweb, в приложении ничего менять не нужно.

## 7. Что обязательно загружать в GitHub / на сервер

Обязательные файлы и каталоги:

```
app/                 маршруты, layout, metadata, robots.ts, sitemap.ts, иконки
app/fonts/           локальные шрифты (.woff2) — без них сайт потеряет типографику
components/          все компоненты и CSS-модули
lib/                 контент, расписание, хелперы анимаций
public/              hero-loop.mp4, hero-poster.{avif,webp,png}, og.jpg, art/, photos/
scripts/             генераторы ассетов (нужны только локально, но пусть лежат)
next.config.mjs
package.json
package-lock.json    обязательно — без него `npm ci` не отработает
tsconfig.json
.env.example
README.md
DEPLOY_TIMEWEB.md
```

**Не загружать** (уже перечислено в `.gitignore`):

```
node_modules/        ставится через npm ci
.next/               создаётся при сборке на сервере
.env, .env.local     локальные значения
next-env.d.ts        генерируется Next.js
tsconfig.tsbuildinfo кэш TypeScript
```

Дополнительно: каталог `reference/` и файлы `public/hero.mp4`, `public/hero.png` —
это исходники для `npm run media`/дизайн-референс. На работу сайта они не влияют;
можно оставить в репозитории или исключить, чтобы не тащить лишние ~2 МБ.

## 8. Что проверить после деплоя

1. **Главная открывается**, заголовок «От души. С веничком. По-русски.» на месте.
2. **Видео первого экрана** `/hero-loop.mp4` проигрывается и зацикливается;
   до его загрузки виден постер `/hero-poster.avif`.
3. **Шрифты**: заголовки — Playfair Display, текст — Inter (не системный serif/sans),
   курсив в акцентах — Playfair Display Italic.
   В DevTools → Network должно быть ровно три `.woff2` из `/_next/static/media/`,
   и **ни одного** запроса к `fonts.googleapis.com` / `fonts.gstatic.com`.
4. **Анимации**: плавная прокрутка (Lenis), появление блоков при скролле (GSAP ScrollTrigger),
   пар на canvas/WebGL, кастомный курсор на десктопе.
5. **Статус расписания** в шапке и в блоке «Расписание» показывает актуальное
   «Открыто до 23:00» / «Откроется в 11:00» / «Сегодня закрыто» — считается по Москве
   на стороне клиента, от таймзоны сервера не зависит.
6. **Телефон**: все ссылки `tel:+79671304027` (проверить на мобильном — открывается набор).
7. **VK**: ссылка ведёт на `https://vk.ru/baniapposad`.
8. **Карта**: кнопка загружает виджет Яндекс.Карт, «Построить маршрут» открывает
   `yandex.ru/maps` с точкой Корнево-Юдинский пер., 10.
9. **SEO**:
   - `https://ваш-домен/robots.txt` — `Host`/`Sitemap` указывают на боевой домен;
   - `https://ваш-домен/sitemap.xml` — корректный `<loc>`;
   - в исходном HTML есть `<link rel="canonical">`, `og:image` → `/og.jpg`
     и JSON-LD `HealthAndBeautyBusiness`.
10. **Мобильная версия**: нижняя панель «Позвонить / Маршрут» зафиксирована,
    горизонтальной прокрутки нет.
11. **Заголовки кэша**: `/art/*` → `max-age=31536000, immutable`,
    `/hero-poster.*` и `/hero-loop.mp4` → `max-age=604800`.
12. **Консоль браузера** без ошибок.

## 9. Шрифты

Шрифты локальные, внешних CDN нет.

| Файл | Начертание | Оси | Размер |
|---|---|---|---|
| `app/fonts/PlayfairDisplay-Variable.woff2` | normal | `wght 400–900` | 95 КБ |
| `app/fonts/PlayfairDisplay-Italic-Variable.woff2` | italic | `wght 400–900` | 93 КБ |
| `app/fonts/Inter-Variable.woff2` | normal | `wght 100–900` | 182 КБ |

Это официальные переменные шрифты Google Fonts тех же версий, что раздавал CDN
(Playfair Display 1.203, Inter 4.001), обрезанные по объединению диапазонов
символов, которые Google отдавал раньше: latin, latin-ext, vietnamese, cyrillic,
а для Inter дополнительно cyrillic-ext, greek, greek-ext. Контуры глифов,
ширины и вертикальные метрики совпадают с прежними файлами до единицы —
типографика не изменилась.

Отличие одно и на итоговый вид не влияет: метрики подменного системного шрифта
(`size-adjust` для Times New Roman и Arial) теперь считаются из самого файла,
а не из таблицы Next.js, и расходятся с прежними на 0,15–0,8 п.п.
Это заметно только в те доли секунды, пока свой шрифт ещё не загрузился.

Лицензия обоих шрифтов — SIL Open Font License 1.1, размещение в составе
проекта разрешено.

## 10. Обновление сайта

```bash
git pull
npm ci
npm run build
# перезапустить приложение в панели Timeweb
```

Правки текста, цен и расписания — только в `lib/content.ts`, затем пересборка.
