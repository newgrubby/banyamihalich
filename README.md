# Баня «У Михалыча» — сайт

Одностраничный сайт общественной бани в Павловском Посаде.
Next.js (App Router) + React + TypeScript, анимации на GSAP / ScrollTrigger / Lenis,
пар — собственный WebGL-шейдер.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Сборка и проверка:

```bash
npm run build
```

```bash
npm run typecheck
```

## Где что менять

| Что | Файл |
| --- | --- |
| **Весь текст, цены, расписание, контакты, SEO** | `lib/content.ts` |
| Логика текущего дня и статуса «открыто/закрыто» | `lib/useBanyaDay.ts` |
| Плавная прокрутка, якоря, определение WebGL | `lib/motion.ts` |
| Цвета, шрифты, отступы, сетка | `app/globals.css` (блок `:root`) |
| Шейдер пара | `components/Steam.tsx` |
| Видео и постер первого экрана | `components/HeroMedia.tsx` |
| Картинки услуг | `public/art/*.svg` |

`lib/content.ts` — единственный источник правды. Поменяли цену или часы работы —
поменялись и карточки, и информационная панель, и микроразметка для поисковиков.

### Расписание

Массив `schedule` в `lib/content.ts`. У каждого дня:

- `weekday` — как в `Date#getDay()` (0 — воскресенье);
- `kind` — `men` / `women` / `sanitary`;
- `openHour` / `closeHour` — часы по московскому времени, `null` = закрыто;
- `hours` — как показывать пользователю.

Текущий день определяется в браузере по часовому поясу `Europe/Moscow`
(`site.timeZone`), а не по времени устройства, — расписание остаётся верным
для гостя из другого региона. Статус пересчитывается раз в минуту.

### Домен

Перед публикацией укажите настоящий адрес сайта в `site.url` (`lib/content.ts`) —
от него зависят canonical, Open Graph, `sitemap.xml` и `robots.txt`.

## Генерация ассетов

Всё производное собирается скриптами — руками правятся только исходники.

### Медиа первого экрана

Исходники: `public/hero.mp4` и `public/hero.png`. Из них делается всё остальное:

```bash
npm run media
```

`scripts/prepare-hero-media.mjs` (нужен `ffmpeg` в PATH) собирает:

- `public/hero-loop.mp4` — **бесшовная плавная петля**. Исходный ролик снят с медленным
  наездом камеры, его последний кадр сильно отличается от первого, и обычный
  `loop` давал бы рывок каждые пять секунд. Скрипт склеивает прямой проход
  с обратным, отбрасывает дублирующиеся кадры на стыках и интерполирует
  движение до 48 кадров в секунду — петля замыкается кадр в кадр, а разворот
  воспринимается мягче. 5 с → 10 с, около 580 КБ.
- `public/hero-poster.{avif,webp,png}` — постер. Кадр подрезается под
  пропорции ролика (1672×900), иначе при появлении видео композиция заметно
  дёргалась бы; смещение кропа подобрано по PSNR относительно первого кадра.
  AVIF весит 34 КБ против 1,7 МБ исходного PNG.
- `public/og.jpg` — картинка для соцсетей 1200×630 из того же кадра.

Заменили `hero.mp4` или `hero.png` — перезапустите `npm run media`.

### Остальное

```bash
npm run art
```

`scripts/generate-art.mjs` — `public/art/venik.svg`. Листья раскладываются
процедурно по силуэту связки: правьте `halfWidth`, `bundle(...)` и палитру
`DARK / MID / LIT`, а не 259 путей.

```bash
npm run assets
```

`scripts/generate-raster-assets.mjs` — `app/apple-icon.png`. Кодирование PNG
написано вручную через `zlib`, внешних зависимостей нет.

## Первый экран

Снизу вверх: постер → видео → шейдер пара → заголовок.

Постер (`<picture>` с AVIF/WebP/PNG) виден сразу и остаётся под роликом —
это элемент LCP, он лёгкий и резкий. Видео проявляется поверх по событию
`canplay`, кадрирование у них совпадает, поэтому подмены не видно.

Ролик не подключается вовсе, если включён `prefers-reduced-motion` или
браузер сообщает про экономию трафика (`Save-Data`, 2G) — остаётся постер.
За пределами первого экрана воспроизведение ставится на паузу.

## Как устроен пар

`components/Steam.tsx` — полноэкранный WebGL-шейдер поверх первого экрана.
В кадре уже есть настоящий пар, поэтому шейдер работает добавочным слоем:
в покое он почти незаметен и оживает от курсора и прокрутки.

- Градиентный шум Перлина с **domain warping** — клубы, а не зацикленная текстура.
- Три струи с разным масштабом, скоростью подъёма и шириной плюс общая дымка,
  которая и проходит перед заголовком.
- Источник струи берётся из DOM: невидимый маркер лежит на кромке ушата
  (`HeroMedia`), поэтому шейдерная струя поднимается оттуда же, откуда идёт
  настоящий пар в кадре, и не «отклеивается» при смене размера окна.
- Курсор мягко расталкивает пар; при начале прокрутки интенсивность растёт,
  к середине ухода первого экрана пар заполняет кадр и затем рассеивается.
- Колонка с заголовком защищена маской `uGuard` — пар там есть, но текст читаем.
- Кадр считается в 0.34–0.5 разрешения и растягивается: пар мягкий,
  ступенек не видно, нагрузка на GPU низкая.

### Запасные варианты

- Нет WebGL, контекст потерян или у устройства слабая графика — включается
  лёгкий слой на Canvas 2D (размытые пятна).
- `prefers-reduced-motion: reduce` — рисуется один статичный кадр, видео не
  подключается, Lenis не запускается, GSAP-анимации заменяются конечным
  состоянием, мерцание света отключается.
- Пар не считается, когда первый экран вне зоны видимости.

## Изображения услуг

Иллюстрации карточек сделаны вектором (SVG) и лежат в `public/art/`. Они
лёгкие, не требуют оптимизации и не создают ложных ожиданий: это баня, а не SPA.

Чтобы заменить их фотографиями, положите файлы в `public/art/` и поменяйте
поле `art` у услуги в `lib/content.ts` — вёрстка (`aspect-ratio`, `object-fit`,
`loading="lazy"`) уже готова. Для растровых фото имеет смысл перейти
на `next/image` в `components/Services.tsx`.

## Карта

Карта не грузится вместе со страницей. Сначала показывается схема
(`components/MapScheme.tsx`), виджет Яндекс.Карт подключается только по
нажатию «Показать карту» — это экономит трафик, не тянет сторонние скрипты
в Core Web Vitals и не отдаёт данные гостя без его действия.

Кнопка «Построить маршрут» и координаты ведут в Яндекс.Карты по
`contacts.coords`.

## Доступность и SEO

- Семантическая разметка: `header` / `main` / `section` / `footer`,
  адрес в `address`, расписание в `ol`, у каждой секции свой заголовок.
- Статус дня объявляется через `aria-live="polite"`, активный день —
  `aria-current="date"`.
- Микроразметка `HealthAndBeautyBusiness` с адресом, координатами,
  часами работы и ценами — собирается из `lib/content.ts` в `app/layout.tsx`.
- `sitemap.xml`, `robots.txt`, canonical, Open Graph и Twitter Card на месте.
